3. How we use it

We use the data above to:

  • operate the marketplace — publish and display listings and stores, and broadcast new listings to the WhatsApp groups the operator has configured;
  • take payment for listings, boosts and store plans, and create the item you paid for once payment completes;
  • keep evidence of the terms you accepted;
  • keep an operational audit trail of administrator and payment actions;
  • keep blocked phone numbers from starting a payment;
  • review reports of bad listings or stores; and
  • secure the service, prevent abuse, and diagnose faults.

4. Who we share it with

We use a small number of third-party providers. Each receives only what it needs to provide its part of the service, and each has its own privacy policy. The providers actually used are:

  • IntaSend — payment provider. Receives the phone number you pay with, the amount and a payment reference, and starts the M-Pesa payment.
  • Cloudinary — image host. Receives the images you upload and serves them back to browsers.
  • Whapi.Cloud — WhatsApp messaging service. Receives the listing summary and the seller's contact link so the listing can be broadcast to the configured WhatsApp groups.
  • Render — hosting provider. Runs the application and its log files.
  • MongoDB Atlas — database provider. Hosts the database that stores the records listed above.
  • Google Fonts — font provider. Serves the typefaces used on the site; the browser requests them directly from Google's font servers.
  • GoatCounter — analytics. Receives page-view information so the operator can see how the site is used.

5. Storage in your browser and analytics

The site stores a few values in your browser's local storage so that a page reload does not lose them. These are:

  • the one-time ownership token for a listing you created, kept so you can edit or delete that listing from the same browser;
  • the one-time ownership token for a store you created, kept for the same reason;
  • the claim token for a Free Grant request you made, kept so the same browser can check its status and redeem the grant once approved (if you clear it, an administrator can issue you a new one); and
  • the ownership token for a payment that is still pending, kept so it can be recovered once the payment completes.

These tokens are stored only in your browser. The server sets no cookies.

The home page loads the GoatCounter analytics script, which reports page views to GoatCounter. You can block or clear this script using your browser settings or a content blocker.
