Rules for any coding agent working on this repository.
1. Every commit that adds, removes or changes behavior must, in the same commit, update docs/CHANGELOG.md, and docs/API_AND_CONFIG.md when a route, variable or limiter changes.
2. A decision that changes a rule in docs/DECISIONS.md must add a new numbered entry; never edit an old entry.
3. Do not merge, push or touch main.
4. Do not weaken, delete or skip tests.
5. Stop and ask when a requirement is unclear; never guess.
6. Every phase ends with an exit-gate report saved as docs/reports/phase-N-gate.md, in addition to being shown in chat.
